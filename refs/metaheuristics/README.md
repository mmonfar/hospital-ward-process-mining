## Licence constraint — read before publishing anything

The BY-ND licence permits redistribution of the document but **not** modified or
transformed versions, *except for personal use*. A PDF-to-markdown conversion is
a transformation. So:

- Keeping `essentials-of-metaheuristics.md` in a **private** working repository
  for personal/internal use is within the licence's personal-use carve-out.
- Publishing it — a public GitHub repo, a hosted docs site, an artifact URL, a
  paper appendix — would be redistributing a derivative work and is **not**
  permitted without the author's consent.

`.gitignore` therefore excludes the generated markdown and the PDF from version
control by default. Anyone who needs them re-runs the parser:

```bash
python tools/parse_reference_pdf.py refs/metaheuristics/Essentials.pdf refs/metaheuristics --slug essentials-of-metaheuristics --source-url "https://people.cs.gmu.edu/~sean/book/metaheuristics/Essentials.pdf"
```

`SELECTION-GUIDE.md` is our own analysis and *is* tracked; it cites the book by
algorithm number and page rather than reproducing it.

## How agents should use this

Do not read the full markdown into context — it is ~863 KB. Look the algorithm
up in `ALGORITHM-INDEX.md`, then pull only the relevant page:

```bash
grep -n "<!-- page 199 -->" refs/metaheuristics/essentials-of-metaheuristics.md
```

This rule is enforced as a token-budget guardrail in `orchestration/graph.yaml`.
