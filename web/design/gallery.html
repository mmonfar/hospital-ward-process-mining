Ward viewer design system

SPEC-005, node N14a. Every token, primitive and state the viewer (N14) and the governance view (N18) are allowed to use. If a screen needs something that is not on this page, the system gains it here first — that is the difference between one visual system and a collection of widgets.

All numbers below are synthetic and exist to exercise the components. Accessibility figures are not printed here on purpose: they are asserted by python -m hwpm.cli design check and by tests/test_design_tokens.py, so that they cannot be stale.

Palette

Two ramps. The teal is the prototype's #16777a extended; the neutral is a slate-green rather than a grey, because a true grey reads cold beside teal and beside the 3D scene. Components never reference a ramp step directly — they use the semantic tokens below it.

Categorical series

Five slots and a sixth aggregate bucket, each with a mark shape and a fill pattern. Five is a cap, not a starting point: under the contrast floor the usable lightness range is about thirty L* units, and past five categories colour stops being decodable — particularly for the significant minority of any clinical audience with a colour vision deficiency. A view needing more distinctions uses position or small multiples.

Type

Four sizes, two weights. Numerals are tabular everywhere, so a column of figures aligns and a changing value does not jitter.

Controls

Tab to any of these to see the focus ring.

Strategy selector and spread

The selector is a radiogroup, not a filter: choosing a definition changes emphasis, never availability. Union and intersection stay drawn as the outer bounds, and the band moves as you change definition. A reader who uses this control should leave less confident in any single number and more confident in the range.

Pareto front browser

Unsorted, unranked, unscored. Today's observed baseline is always drawn, so "better" is anchored to current reality. Infeasible schedules are marked on the line itself. Hover, or focus the plot and use the arrow keys.

States

An empty result is a finding, not a failure — a ward whose rounds already coincide is the outcome this project is trying to produce. The loading placeholder is hatched rather than skeletal because a grey bar chart of placeholder bars is a picture of data that does not exist.

Motion

Three durations. The long one is reserved for motion that is itself the information — a clinician walking a route, a schedule morphing into another. Panels never animate in. Everything respects prefers-reduced-motion; when it is set, transitions arrive at the same final state immediately.
